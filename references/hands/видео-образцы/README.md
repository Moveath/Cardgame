# Видео-образцы: как должны вести себя пальцы

Восемь роликов, которые автор сгенерировал в Gemini 13–14 ноября 2026 года как образец поведения пальцев. Важно именно поведение: как кисть лежит, как сжимается кулак, где лежит большой палец. Вены, веснушки и цвет кожи с этих роликов переносить не нужно.

| Файл | Что на нём |
| --- | --- |
| `01-веер-раскрыть.mp4` | Левая рука берёт карты со стола и держит веер из шести карт, вид сверху от игрока |
| `02-ход-картой.mp4` | То же, затем правая рука берёт крайнюю карту из веера и кладёт на стол |
| `03-класс.mp4` | Правая кисть лежит на сукне, сжимается в кулак, показывает «класс», ложится обратно; вид сбоку |
| `04-фу.mp4` | Кулак, большой палец вниз; вид с тыла кисти |
| `05-указать.mp4` | Кисть лежит расслабленно, поднимается, показывает указательным, ложится |
| `06-удар-кулаком.mp4` | Кисть лежит, сжимается в кулак, опускается на стол, раскрывается |
| `07-кулак-и-не-знаю.mp4` | Кулак, затем открытая ладонь вверх («не знаю») |
| `08-кулак-не-знаю-кулак.mp4` | Длинный ролик: кулак, ладонь вверх, кулак на столе |

Точки суставов с этих роликов снимает `tools/mocap/hand_pose.py`, в углы нашей руки переводит `tools/mocap/retarget.py` (см. `tools/mocap/README.md`). Что из этого получилось и что взято в игру — `Documentation/3D_HANDS_IMPLEMENTATION.md`, раздел про пальцы от 2026-11-14 и описание хвата веера и лежащей кисти (2026-11-15: обе позы поставлены по ролику 01).
