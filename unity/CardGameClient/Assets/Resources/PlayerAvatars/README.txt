    PlayerAvatars/yegor/yegor_01..12.png
    PlayerAvatars/marat/marat_01..12.png

Отличие от соседней папки Avatars: там двенадцать выдуманных персонажей, по одному
образу на каждого, а здесь один человек в двенадцати костюмах.

Себе аватар выбирает игрок на экране «Аватар». За соперников садятся друзья из этой
папки — по одному образу с каждого, чтобы за столом были разные люди. Бот берёт и имя
своего лица. Общий пул выдуманных персонажей идёт в ход, только если друзей не хватило.

Папка сама становится набором: код ищет имя файла до подчёркивания (marat_03 ->
marat). Подпись по-русски — в AvatarCatalog.GroupTitles.

Как добавить нового человека (промпт для генерации, нарезка, куда класть) —
см. AVATARS.md в корне репозитория.
