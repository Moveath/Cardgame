Портреты игроков.

Кладите сюда квадратные PNG — по одному на портрет. Имя файла любое, например:
  avatar_01.png, avatar_02.png, ...

Что происходит дальше:
- игра сама подхватывает все картинки из этой папки (Resources.LoadAll) —
  список нигде прописывать не нужно, достаточно положить файл;
- каждому игроку на партию случайно достаётся свой портрет;
- картинка обрезается кругом-маской, поэтому лицо лучше размещать по центру
  и оставлять небольшой запас по краям;
- если папка пустая, за столом рисуются старые цветные кружки с буквой —
  ничего не ломается.

Рекомендуемый размер — 512x512. Настройки импорта (спрайт, без сжатия, мипмапы)
проставляются автоматически, руками в инспекторе ничего трогать не надо.
