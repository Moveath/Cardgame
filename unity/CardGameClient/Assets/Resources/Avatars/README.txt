Общий пул портретов — выдуманные персонажи, раздаются игрокам случайно на партию.

Кладите сюда PNG с прозрачным фоном — по одному на портрет:
  avatar_01.png, avatar_02.png, ...

Что происходит дальше:
- игра сама подхватывает все картинки из этой папки (Resources.LoadAll) —
  список нигде прописывать не нужно, достаточно положить файл;
- персонаж рисуется целиком, без кружка и подложки: он «сидит» прямо на сукне,
  поэтому фон должен быть именно прозрачным, а не белым;
- если папка пустая, за столом рисуются цветные кружки с буквой — ничего не ломается.

Лица реальных людей сюда класть НЕ надо: для них есть соседняя папка PlayerAvatars,
откуда портрет достаётся по имени игрока, а не случайно.

Размер примерно 250x280 (погрудный портрет). Настройки импорта (спрайт, без сжатия,
мипмапы) проставляются автоматически, руками в инспекторе ничего трогать не надо.
