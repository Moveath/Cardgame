# Позы рук: готовые позы и видео живой руки

Позы пальцев 3D-рук приходят из точек суставов кисти, а не подбираются на глаз. `retarget.py` переносит точки на руку игры в пределах живых суставов. Источников два, вход у них одинаковый — 21 точка кисти:

1. **Готовые позы** — библиотека Godot XR Tools (CC0), 35 поз кисти. Работает сейчас.
2. **Видео** — MediaPipe Hand Landmarker (Google). 14 ноября 2026 года обработаны ролики-образцы, которые автор сгенерировал в Gemini (`references/hands/видео-образцы`); съёмка своей руки отложена, список роликов для неё — в конце.

Подробнее о руках — `Documentation/3D_HANDS_IMPLEMENTATION.md`.

## Перенос на руку игры

`retarget.py` подбирает углы суставов руки игры так, чтобы фаланги смотрели туда же, куда в источнике, в осях кисти. Числа выходят как в `scripts/3d/hands/poses.py`: развод, основание, средний, дальний сустав; у большого пальца повороты основания и два сгиба.

- Каждый угол держится в пределах живого сустава. Те же пределы стоят в `poses.limited`: через них проходит любая поза перед тем, как попасть в клип.
- Дальний сустав сгибается примерно на две трети среднего, согнутый палец вбок не отводится.
- Правая и левая рука в числах симметричны, так что позу одной руки можно поставить на другую.

После каждого изменения скелета рук выгрузить его заново: `blender art3d/hands/CardCity_Hands.blend --background --disable-autoexec --python scripts/3d/hands/export_rig.py` (пишет `rig_rest.json`).

## Готовые позы

Источник — `art3d/hands/source/godot-xr-tools-hands/animations_hand_l.blend`: 35 поз левой кисти из репозитория GodotVR/godot-xr-tools (`addons/godot-xr-tools/hands`), лицензия CC0, автор Miodrag Sejic (`License.md` и `About.md` лежат рядом).

```
blender art3d/hands/source/godot-xr-tools-hands/animations_hand_l.blend --background --factory-startup --disable-autoexec --python scripts/3d/hands/library_points.py
tools/mocap/.venv/Scripts/python.exe tools/mocap/retarget.py tools/mocap/library/xr_tools.json --out tools/mocap/library/xr_tools_poses.json
blender art3d/hands/CardCity_Hands.blend --background --disable-autoexec --python scripts/3d/hands/library_sheet.py -- "Default pose" Grip Thumb Sign_Point
```

- `library_points.py` пишет точки суставов каждой позы в `library/xr_tools.json`.
- `retarget.py` переводит их в числа поз — `library/xr_tools_poses.json`.
- `library_sheet.py` рендерит руку игры в выбранных позах с тыла и с ладони (`screens/3d-hands/library`). По листу решают, какая поза годится.

**Что показала проверка (2026-11-13).** Это позы для VR-контроллеров, а не съёмка живой руки:

- Годятся: открытая ладонь (`Default pose`, `Sign 5`, `Straight`), кулак (`Grip`), «класс» (`Thumb`), указательный (`Sign_Point`).
- Не годятся: расслабленные и хватательные позы (`Rounded`, `Cup`, `Grip 1`–`Grip 5`, щипки). Дальний сустав в них согнут так же сильно, как средний, а в кулаках — на 105–114° при пределе живого пальца около 80°. На руке игры это даёт «когти».
- Готовой позы «держать веер карт» в библиотеке нет. Хват веера и кисть на сукне с 15 ноября 2026 года поставлены по видео-образцам автора (`references/hands/видео-образцы`, ролик 01), до этого — по фото его руки (`references/hands/моя-рука/исходники`); из библиотеки в игре — положение большого пальца лежащей кисти (`Default pose`).

Другая библиотека подключается так же: скрипт, который пишет `{"poses": {имя: {"side": "Left" или "Right", "world": [21 точка]}}}` в порядке MediaPipe (запястье; большой палец — основание, два сустава, кончик; затем указательный, средний, безымянный, мизинец — основание, средний сустав, дальний сустав, кончик).

## Видео

1. `hand_pose.py` — MediaPipe находит в каждом кадре 21 точку кисти в объёме. Рядом с файлом кладутся `<имя>.json` с точками и `<имя>-points.jpg` для проверки глазами.
2. `retarget.py` — тот же перенос, что для готовых поз.

Проверено на листе `генерации/12-жесты`: точки ложатся на все шесть жестов; кулак, «класс» и «не знаю» сходятся с кадром в пределах 11–21°, «указать», «фу» и стук на одиночных сгенерированных кадрах неточны.

**Ролики-образцы из Gemini (2026-11-14).** Углы нашей руки по кадрам первых пяти роликов лежат в `tools/mocap/video` (выход `retarget.py`). Рука найдена во всех кадрах. Надёжно читаются удержанные позы, где пальцы видны: кулак и «класс» — промах около 20°, значения устойчивы от кадра к кадру. Не читаются кисть плашмя с бокового ракурса, переходы между позами и пальцы, закрытые картами: промах 40–85°. Ракурс один, закрытые пальцы библиотека угадывает. Поэтому числа с видео — отправная точка, итог сверяется глазами: `scripts/3d/hands/match_view.py` рендерит нашу руку с ракурса ролика. Для переходов нужны ролики с двух ракурсов. Хват веера (ролик 01) числами не снялся: пальцы закрыты картами. Он поставлен по кадрам ролика — пробные позы рендерятся с места игрока и сверяются с кадром (`screens/3d-hands/хват-как-на-видео.jpg`).

### Установка

Окружение и модель в git не входят (`.gitignore`), их ставят заново:

```
uv venv tools/mocap/.venv --python 3.13
uv pip install --python tools/mocap/.venv/Scripts/python.exe mediapipe opencv-python
curl -L -o tools/mocap/hand_landmarker.task https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task
```

### Запуск

```
tools/mocap/.venv/Scripts/python.exe tools/mocap/hand_pose.py --out <папка> <фото или видео> ...
tools/mocap/.venv/Scripts/python.exe tools/mocap/retarget.py <папка>/<имя>.json --out <позы.json> [--hand Right|Left]
```

### Что снимать, когда появится возможность

Видео кладутся в `references/hands/моя-рука/видео/`.

**Как снимать.** Телефон стоит на подставке на уровне глаз и смотрит на стол сверху вниз, как камера в игре. Кадр горизонтальный, свет дневной, без зума. Рукав закатан. Вся кисть с запястьем всё время в кадре: на фото с веером, где кисть обрезана краем кадра, рука не нашлась.

**Ролики.** Каждый 4–6 секунд, начинается и кончается рукой, спокойно лежащей на столе. Веер держит левая, жесты и взятие карты — правая, как в игре.

| Файл | Что |
| --- | --- |
| В1 | Левая держит веер из 6 карт: 3 секунды спокойно, потом чуть перехватывает |
| В2 | Левая лежит на столе без карт |
| В3 | Правая лежит на столе |
| В4 | Правая берёт карту из веера и кладёт на стол |
| Ж1–Ж6 | Правая: «класс», «фу», показать на соперника, три раза постучать пальцами по столу, «не знаю» ладонью вверх, кулак на стол |

Если не трудно, В1, В4 и Ж1–Ж6 ещё раз сбоку: телефон справа от руки, на её высоте. Имена те же, с буквой «б» (Ж1б). С двух сторон сгибы пальцев находятся точнее: с одного ракурса закрытые пальцы библиотека угадывает.

Готовые клипы Unity для этого скелета подключаются без пересборки рук: файл `.anim` с именем клипа (`Take_ThumbsUp.anim` и так далее) кладётся в `unity/CardGameClient/Assets/Resources/ThreeD/Hands/Clips`, затем пересобирается контроллер (`scripts/3d/HandsAnimatorBuilder.cs`).
