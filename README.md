# CardGame

Платформа онлайн-карточных игр. Первый режим — подкидной дурак, дальше добавляются другие
режимы со своими правилами поверх общего ядра.

## Структура

| Проект | Назначение |
|---|---|
| `src/CardGame.Core` | Правила и состояние игр. Чистый C#, ноль зависимостей от Unity. Работает и на клиенте, и на сервере. |
| `src/CardGame.Bots` | Боты: автотесты, игра с компьютером, добор пустых мест в комнатах. |
| `src/CardGame.ConsoleDemo` | Прогон партии в консоли — быстрая проверка логики без редактора. |
| `tests/CardGame.Core.Tests` | Юнит-тесты и прогон сотен партий ботами. |
| `unity/CardGameClient` | Unity-клиент: только отображение, правила берёт из `CardGame.Core`. |

`CardGame.Core` таргетит `netstandard2.1` — эту же сборку подключит Unity-клиент и будущий сервер,
поэтому правила пишутся один раз.

## Команды

```bash
dotnet test                                  # прогнать тесты
dotnet run --project src/CardGame.ConsoleDemo         # случайная партия
dotnet run --project src/CardGame.ConsoleDemo -- 777  # партия по seed 777 (воспроизводимая)
```

После правок в `CardGame.Core` или `CardGame.Bots` нужно пересобрать логику для Unity:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-for-unity.ps1
```

Скрипт кладёт свежие DLL в `unity/CardGameClient/Assets/Plugins/CardGame/`. Эти файлы —
результат сборки, поэтому в репозиторий не попадают: после клонирования запусти скрипт.

**Запускать лучше при закрытом редакторе.** Подмена плагина на ходу заставляет Unity
перекомпилировать всё прямо во время работы, и сборщик `bee_backend` иногда не может
подключиться к редактору по именованному каналу. Выглядит это как «All compiler errors
have to be fixed before you can enter playmode», хотя ни одной ошибки в коде нет — в логе
`unity/CardGameClient/Logs/Editor.log` не будет ни строчки `error CS`, зато будет
`bee_backend: error: Failed IPC_Client_InitializeAndConnectToParent`. Лечится перезапуском
Unity; если повторяется — удалить папку `Library/Bee` при закрытом редакторе, это кэш
сборки и он соберётся заново.

Seed определяет перемешивание колоды, поэтому любой баг воспроизводится по номеру раздачи.

## Дальше

Локальная оболочка приложения уже доступна в главном меню: профиль, друзья,
комнаты, магазин, прогресс, банк и обучение. Подробности и границы серверного
этапа — в [docs/player-hub.md](docs/player-hub.md).

1. Unity-клиент в `unity/` — только отображение, правила берёт из `CardGame.Core`.
2. Сервер на ASP.NET Core: комнаты, WebSocket, авторитетная валидация ходов.
3. Аккаунты, друзья, чат, рейтинг.
4. Новые режимы — отдельные папки в `Core/Games/`, общая обвязка переиспользуется.
